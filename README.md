# งานวิจัยร่างธรรมนูญ 2027

เว็บไซต์เผยแพร่งานวิจัยอิสระเกี่ยวกับการเปรียบเทียบโครงสร้างการปกครอง การกระจายอำนาจ และธรรมาภิบาลของสภาคริสตจักรในประเทศไทย ระหว่างธรรมนูญ ค.ศ. 1998 และร่างธรรมนูญ ค.ศ. 2027

เว็บไซต์นี้จัดทำขึ้นเพื่อการศึกษาและการพิจารณาอย่างรอบคอบ ไม่ใช่เว็บไซต์ทางการของสภาคริสตจักรในประเทศไทย และเนื้อหาการวิเคราะห์เป็นความรับผิดชอบของผู้วิจัย

## การใช้งาน

เป็นเว็บไซต์ Static จึงสามารถเปิด `index.html` ได้โดยตรง หรือใช้เซิร์ฟเวอร์ภายในเครื่องเพื่อทดสอบลิงก์ PDF:

```bash
python3 -m http.server 8765
```

จากนั้นเปิด <http://127.0.0.1:8765/>

## โครงสร้างไฟล์

```text
.
├── index.html       # หน้าเว็บไซต์หลัก รวม HTML, CSS และ JavaScript
├── favicon.svg      # ไอคอนเว็บไซต์
├── robots.txt       # แนวทางสำหรับ search engine crawler
└── docs/            # รายงานวิจัยและเอกสารอ้างอิง PDF
```

## เอกสารประกอบ

เอกสารในโฟลเดอร์ `docs/` ประกอบด้วยรายงานวิจัยฉบับเต็ม บทคัดย่อ กิตติกรรมประกาศ ธรรมนูญ ค.ศ. 1998 ระเบียบปฏิบัติ นโยบายและยุทธศาสตร์ และร่างธรรมนูญ ค.ศ. 2027 สำหรับการศึกษา

ร่างธรรมนูญ ค.ศ. 2027 เป็นเอกสารร่างที่ยังไม่มีผลใช้บังคับในช่วงเวลาของการศึกษา และไฟล์ต้นฉบับเป็นภาพสแกน จึงอาจค้นหาหรือคัดลอกข้อความไม่ได้ครบถ้วน

## การเผยแพร่

ก่อนเผยแพร่สู่สาธารณะ ควรตรวจสอบ:

- สิทธิในการเผยแพร่สำเนาเอกสาร PDF
- รุ่นและสถานะล่าสุดของเอกสารทุกฉบับ
- ความถูกต้องของการอ้างอิง เลขข้อ และเนื้อหาที่ถอดจากเอกสาร
- โดเมนจริง เพื่อเพิ่ม canonical URL และ sitemap หากจำเป็น

## สถานะโครงการ

เว็บไซต์เป็นผลงานวิจัยอิสระ ฉบับเผยแพร่ในเว็บไซต์ระบุช่วงเวลาเดือนตุลาคม ค.ศ. 2026 และมีคำชี้แจงว่าไม่ใช่มติหรือคำวินิจฉัยอย่างเป็นทางการขององค์กร
